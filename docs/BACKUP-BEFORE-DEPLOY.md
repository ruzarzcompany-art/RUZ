# نسخة احتياطية قبل تنفيذ نظام تقفيل الكاشير والنقدية

هذه الإضافة تُنشئ جداول جديدة فقط ولا تُعدّل أي جدول قائم ولا أي صف محفوظ:
التقفيلات السابقة وبنودها وحساباتها تبقى كما هي حرفياً. ومع ذلك لا يُنشر أي
ترحيل على قاعدة بيانات الإنتاج قبل أخذ نسخة احتياطية كاملة.

## 1) نسخة قاعدة البيانات (Neon / Netlify Database)

### أ. لقطة زمنية من لوحة Neon (الأسرع والموصى به)

1. افتح مشروع قاعدة البيانات في Neon.
2. من فرع الإنتاج اختر Branches ثم Create branch من نقطة زمنية (Point in time).
3. سمِّ الفرع باسم واضح مثل backup-before-cash-closing ودوِّن وقت اللقطة.
4. اللقطة نسخة كاملة قابلة للرجوع إليها بلا أي تأثير على فرع الإنتاج.

### ب. نسخة ملف (احتياط إضافي خارج المنصّة)

    pg_dump --no-owner --no-privileges --format=custom \
      "$DATABASE_URL" > ruz-backup-before-cash-closing.dump

للاسترجاع عند الحاجة:

    pg_restore --clean --if-exists --no-owner --no-privileges \
      --dbname="$DATABASE_URL" ruz-backup-before-cash-closing.dump

تحقّق من حجم الملف بعد التصدير، والملف الفارغ أو الأقل من بضعة كيلوبايتات
يعني أن التصدير لم ينجح فلا تكمل النشر.

## 2) نسخة الكود

الكود محفوظ في فرع مستقل: feature/cash-closing-system، و main يبقى كما هو
إلى أن يُدمج الفرع. للرجوع في أي لحظة يكفي إلغاء الدمج أو النشر من main.

## 3) التحقق بعد النشر

1. افتح شاشة تقفيل الكاشير وتأكد أن التقفيلات القديمة تظهر بأرقامها كما كانت
   (المتوقّع والمعدود والفارق) — الحقول الجديدة تُعرض صفرية ولا تغيّر شيئاً.
2. افتح تقرير تقفيلات الكاشير وقارن إجمالي شهر سابق قبل النشر وبعده.
3. تأكد أن أي شهر سابق لا يظهر بحالة (بانتظار الاعتماد) ما لم يُجهَّز يدوياً.

## 4) الترحيلات

ترحيل هذه الإضافة يضيف أربعة جداول جديدة فقط:

- cash_expenses — السجل الموحّد للمصاريف والمشتريات النقدية
- provider_settlements — تسويات الشبكات وتطبيقات التوصيل
- monthly_cash_closings — إقفال الشهر والترحيل
- cash_notifications — إشعارات ملخّص الإقفال

لا يوجد فيه أي ALTER أو DROP على جدول قائم، فالرجوع عنه يكون بحذف الجداول
الأربعة وحدها:

    DROP TABLE IF EXISTS cash_notifications;
    DROP TABLE IF EXISTS monthly_cash_closings;
    DROP TABLE IF EXISTS provider_settlements;
    DROP TABLE IF EXISTS cash_expenses;
